# Agent Rules

## Language: Always Respond in English

**CRITICAL RULE — Always apply, no exceptions:**

- Always respond in **English** in all chat responses, console output, terminal messages, code comments, and any other communication — regardless of what language the user writes in (Bangla, English, or any other language).
- **Only exception:** If the user explicitly asks you to write a specific document or `.md` file in Bangla, you may use Bangla in that specific file/document only.
- This rule exists because Bangla fonts do not render well in the terminal.
